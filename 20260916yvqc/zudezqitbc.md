# 心脏的“门”坏了，他们这样换的……

> 更新时间：2026-09-16 (UTC+8)

**介入微创手术**

**为老人置换心脏**

**“开关阀门”**

近日，东南大学附属中大医院心血管内科主任马根山教授团队为多位高龄主动脉瓣狭窄患者成功施行**经导管主动脉瓣置换术**。其中，68岁的张奶奶（化姓）患有主动脉瓣重度狭窄，同时伴有多种基础疾病，在施行经导管主动脉瓣膜置换术后，恢复良好，**重获健康的“心门”**。

**1**

**老人频频胸痛**

**主动脉瓣重度狭窄**

张奶奶从半年前开始，就经常出现胸闷胸痛的情况。胸痛的地方位于心前区，感觉每次活动过后胸闷胸痛的症状更重。“每次**胸口特别难受，接着就开始头晕，眼前一黑**，但大多持续数秒钟后，休息休息就好了。不知道为啥，最近半年还总是觉得自己**浑身没力气，双腿还有些水肿**。这几天，情况越来越重，所以就来到中大医院找马主任团队帮忙看看。”张奶奶告诉记者。

据了解，张奶奶患有**主动脉瓣重度狭窄，心功能三级，同时合并风湿性关节炎、高血压2级（极高危）、输尿管结石、血小板减少等，病情严重**。心血管内科联合心脏外科、麻醉手术与疼痛管理科、重症医学科、医学影像科，进行疑难危重症多学科会诊，结合多方面因素进行全面评估，为李奶奶制定了严密的手术方案。

**2**

**多学科协作**

**置换心脏“开关阀门”**

由于张奶奶冠状动脉位置低，外周血管和心室腔较小，是一名**复杂高危的主动脉瓣重度狭窄患者**，同时还有“**自杀左心室**”的手术风险，术中很容易出现循环崩溃以及心跳骤停等危急情况，再加上老人主动脉瓣及二尖瓣钙化严重，基础心跳慢，心率平均每分钟不超过50次，这就要求团队要有快速精准的反应和规范精细的操作。

在多学科的通力合作下，由中大医院心血管内科主任马根山教授、丁建东主任医师、陈立娟主任医师及其医护团队成功为张奶奶施行全麻下经导管主动脉瓣置换术，术后患者恢复良好。

**3**

**介入微创治疗**

**让患者重获“心门”**

**1**

**那么，主动脉瓣到底是个啥呢？**

其实，心脏相当于一个“泵”，每天将血液泵出送往全身，而**主动脉瓣就是一个“开关阀门”**。心脏收缩时，血流冲开主动脉瓣，将血液输送出去；心脏舒张时，主动脉瓣闭合。**主动脉瓣狭窄是老年人常见的心脏疾病之一**，由于瓣膜老化，钙沉积使瓣膜失去弹性，无法正常打开关闭，心脏排血大大受阻，会发生**呼吸困难、心绞痛甚至猝死**。

**2**

**经导管主动脉瓣膜置换术**

丁建东主任医师介绍，经导管主动脉瓣膜置换术，是在患者股动脉上切开一个小口，将心导管送达患者手术部位，先对狭窄的主动脉瓣进行球囊扩张，推开老化瓣膜，换上新的人工瓣膜。更换瓣膜的过程只有短短几分钟，**创伤小，恢复快**。

**3**

**介入微创治疗 提高晚年生活质量**

马根山教授指出，对于老年心脏瓣膜病的治疗，以前需要开刀进行换瓣手术，**但很多高龄老人因多病缠身，难以耐受外科手术**。近年来，中大医院心血管内科致力于老年心脏瓣膜病的介入微创治疗，可采用经导管进行主动脉瓣膜置换，这也是中大医院从2014年以来开展的特色技术。

对于二尖瓣反流、三尖瓣反流、肺动脉瓣严重反流也**可通过介入微创手术进行修补，让高龄患者通过微创手术方式获得新生**，提高晚年生活质量。
