# 【矿总青年专家】葛行新：让骨科技术更有温度和生命力

> 更新时间：2026-09-16 (UTC+8)

**矿总青年****人人了不起 个个正能量**

未来属于青年，希望在于青年。习近平总书记在党的二十大报告中强调，当代中国青年生逢其时，施展才干的舞台无比广阔，实现梦想的前景无比光明。总书记对抓好新时代青年工作提出明确要求，对青年一代寄予的殷切期望。

在这个追梦者的时代，徐州矿务集团总医院有这么一群青年拼搏努力，成就梦想，让青春之花在医疗卫生事业的发展历程中绚丽绽放。

院团委推出《矿总志青春》栏目，邀请医院优秀青年代表讲述成长追梦之路，分享矿总青年在临床、科研、技术、创新等各方面内容，引导全院青年在推动医院高质量发展新征程中贡献青春力量。

**本期青年**

副主任医师

骨  科

葛行新是医院骨科团队的中坚骨干，经过近20年的实践与磨砺，他在治病救人的事业中坚守初心，护佑生命，在骨科微创技术领域潜心研究，锤炼本领，他让技术焕发生命力，让更多患者获益。**0****1****与医学的不解之缘**

回想当初为何从医，葛行新并非立下“悬壶济世”的鸿鹄之志，不过是一个简单而朴素的想法。“我当年高考结束，没有多么崇高的理想与抱负，只想有一份安稳的工作，就这样稀里糊涂地填报了医学专业。”

学医压力非常大，进入大学后，一本本大部头的专业书，每个内容都是重点，考试复习昏天黑地。葛行新开始怀疑自己“学啥专业不好，非要选择这条路”，一度想过退学的念头。之后的一场大病，却改变了他的想法。当医生能帮助生病的人，能给自己和家人看病，也能帮助那些需要帮助的人，何乐不为。

每一个学医的男生都有一个外科梦，葛行新也不例外。毕业之后，他来到徐矿总医院从事骨科临床一线工作，开启了“铁骨铮铮、解除苦痛”医学事业。他常说“穿上这身白大褂已近二十载，与医结缘，是我的幸运。”

**0****2****日积月累渐入佳“镜”**

进入临床一线工作之后，葛行新师从魏东主任、李华主任。有了良师指导，他全身心投入到临床工作中，打下了扎实的基本功，骨科的常见病他基本都能可以独立处理。

医学专业是一门日新月异的学科，大刀阔斧的“骨”时代已经终结，在安全有效的前提下，微创是外科发展的方向。为此，葛行新2013年到上海长征医院进修学习，带回来了先进技术、先进理念。

微创和传统术式相比，视野非常小，学习曲线长，对医生自身技术要求非常高。葛行新在前期积累良好的手术基础上，率先开展微创下腰椎融合术（MIS—TILF），熟练开展椎间孔镜，在脊柱内镜技术治疗椎间盘突出及椎管狭窄有独到见解。

随着微创技术不断更新，一种专为椎管狭窄而生的UBE技术如雨后春笋，遍地开花。葛行新凭借丰富的“镜”下经验，很快掌握了这一项新兴的微创脊柱内镜技术，并将手术心得体会在省骨科年会上分享。除此之外，他率先开展了MIS-TILF、UBE、更微创的CBT螺钉固定技术、经椎间孔入路椎体成形术、椎间孔镜下纤维环修复缝合术等新技术。

“新技术既要引进来更要落下来，为患者带来实实在在的好处。”葛行新将自己得心应手的微创技术送到病患的身上。

创伤小、出血少、痛苦轻、恢复快，能减少患者对手术的疼痛和畏惧，微创技术的开展得到广大患者的一致好评，众多患者慕名而来。用技术帮助更多的患者，这是葛行新作为医生最有意义的事。
**0****3****科研创新回馈临床**

葛行新一直坚持认为“科研要从临床当中来到临床当中去”。作为一个外科医生，不但要会做手术，而且要会做科学研究。葛行新努力通过科学研究帮助解决更多的临床问题，他优化穿刺和骨水泥注入技术pvp治疗上胸椎骨质疏松性骨折，降低了手术风险，缩短了手术时间，使患者更好的耐受手术，获得徐州市新技术引进奖三等奖。

葛行新科研成果不断，2020年骨质疏松椎体骨折短期成重度压缩的致病危险因素及优化PVP关键治疗技术的应用研究获得淮海科学技术奖二等奖；2021年miRNA对OVCF的调控机制及个性化PVP技术构建和应用的研究获得淮海科学技术奖一等奖。近3年内获得3项实用新型专利，主编《骨科常见病临床诊疗实践》骨科专著一部，分别在《中国骨与关节损伤》、《中国伤残医学》《中国实用医药》杂志发表论文数篇。

在今年在江苏省骨科年会上，葛行新将CBT螺钉技术及椎体成形技术做大会学术交流，在全国脊柱脊髓会议上分享机器人辅助下椎体成形术，得到同行的一致好评与认可，扩大了医院及科室的知名度。

对于未来的努力方向，葛行新认为“医学的道路上没有捷径可走，是一条选择了就要不断更新知识的道路，唯有不断创新、不断学习更新技术。同时应做到良好的有效沟通并不断提升服务水平，才能让技术具有生命力，才能得到广大患者的认可，才是大家心中可以信赖的医师。”
