# “睡一觉”就能完成的无痛取卵是怎么一回事？

> 更新时间：2026-09-16 (UTC+8)

在经历促排打针的痛苦过程，终于等到取卵的日子，相信这对于进行试管助孕的姐妹，既兴奋又害怕，兴奋的是：打了这么多的针，终于等到了收获的时候。害怕的是：取卵应该会很痛吧！别怕，我们中心开展的无痛取卵手术，让姐妹们“睡一觉”就完成取卵过程了。但是又有些姐妹心里犯嘀咕：“无痛取卵用的麻醉药，会不会对我的卵子质量有影响呢？”“麻醉药用了，我会不会记忆力下降，会不会变笨啊”…针对这些问题，我们来聊一聊无痛取卵那些事。

本中心目前开展的无痛取卵术，是麻醉医生通过静脉麻醉的方式，使用麻醉药物对中枢神经系统产生抑制作用，让患者毫无痛苦地在睡眠中完成整个取卵过程。但是这些麻醉药物在很短的时间内就会被分解代谢，作用也随之解除，所以整个麻醉过程是可控和暂时性的，不会改变脑细胞的功能结构，不会对患者产生持续的影响，因此，对于“麻醉会影响人的记忆力，会使人变笨”是没有科学依据的。

而且现有的文献报道，静脉麻醉对卵母细胞的质量及试管婴儿治疗结局没有不良影响：即对受精率、卵裂率、着床率、临床妊娠率等无显著影响。但是能缓解女性的痛苦，安抚他们的情绪。

那么无痛取卵有什么注意事项呢？

**术前注意事项：**

1. 禁食禁饮：目的是预防围手术期发生恶心、呕吐、返流、误吸造成患者缺氧，因此术前禁食禁饮的具体时间，请大家一定要遵医嘱。

2. 不佩戴首饰且不化妆：佩戴首饰会影响静脉输液，化妆会影响麻醉医生对您面色及唇色甲床等的观察。

3. 伴有其他全身性疾病等情况请及时告知，如既往有过敏史、手术史，取卵当日有发热、咳嗽，特殊用药病史（如高血压、糖尿病或其他影响甲状腺功能的药物等等）请务必告知麻醉医生，由麻醉医生根据情况判断能否进行麻醉。

4. 就诊卡内有适量的余额，以便医生术中用药的收费。

**术后注意事项：**

1.术后困乏：取卵术后患者会稍感困乏，但是这种感觉会随着药物的代谢慢慢消失，在此期间，患者要注意体位性低血压，改变体位时要遵循起床三步曲（平躺30秒、坐起30秒、站立30秒），上卫生间时需家属陪同，以防晕厥、跌倒。

2.术后饮食：术后2小时后可先试饮少量开水，无呛咳等不适后逐步过渡到正常饮食。

3..术后离院时间：术后在本中心观察2-4小时，生命体征平稳，没有恶心、呕吐、头晕等不适即可回家，术后必须要有家属陪同。

4.术后活动：术后24小时内禁止驾车及进行精细、高空作业等危险活动。

 **最后祝各位姐妹好孕啦！**
